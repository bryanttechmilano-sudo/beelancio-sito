# Beelancio · sito di presentazione

Anteprima del sito di **Beelancio**, il gestionale per chi lavora in proprio: bilancio per attività, movimenti, scadenze, clienti, agenda, progetti, riparazioni e magazzino.

Un progetto di Bryant Developer. L'app non è ancora aperta al pubblico: questo repository contiene solo il sito (HTML, CSS e JavaScript, senza librerie esterne).

Il sito è nella cartella `sito/`. Cloudflare lo pubblica da solo a ogni aggiornamento di questo repository (vedi `wrangler.jsonc`).
